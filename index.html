🚀 Repositório APT de Inteligência Artificial para Termux

Servidor e repositório de pacotes APT nativos com bibliotecas de Inteligência Artificial e Ciência de Dados pré-compiladas para Termux na arquitetura ARM64 (aarch64) com Python 3.14+.

⚡ Ativação Rápida (Executar apenas 1 vez)

Adicione o repositório à lista de fontes do seu Termux:

echo "deb [trusted=yes] https://raw.githubusercontent.com/W3skerSec/termux-ai-wheels/gh-pages/ ./" > $PREFIX/etc/apt/sources.list.d/w3skersec.list && pkg update

📦 Instalação Direta de Pacotes

Instale os pacotes de IA diretamente pelo gerenciador oficial do Termux:

# Instalar Keras 3 (configurado para backend PyTorch nativo)
pkg install keras

# Instalar PyTorch isoladamente
pkg install torch

# Instalar Scikit-Learn
pkg install scikit-learn

🛡️ Garantias Técnicas de Estabilidade

  • ✓ Sem Gambiarras ou Symlinks: Os binários ELF do PyTorch foram corrigidos na tabela DT_NEEDED com patchelf para apontar para a libabsl_base_cpu_detect.so oficial do Termux.
  • ✓ Compilação Nativa Clang / OpenMP: Scikit-Learn compilado com a toolchain padrão LLVM do Android com suporte a threads paralelas OpenMP.
  • ✓ Resolução Automática: O comando pkg install keras puxa todas as dependências nativas automaticamente sem intervenção manual.
