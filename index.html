🚀 Termux AI APT Repository

Repositório APT com pacotes nativos de Inteligência Artificial para Termux (ARM64 / Android).

⚡ Como ativar no seu Termux (1 comando):

echo "deb [trusted=yes] https://w3skersec.github.io/termux-ai-wheels/ ./" > $PREFIX/etc/apt/sources.list.d/w3skersec.list && pkg update

📦 Como instalar pacotes:

pkg install keras
pkg install torch
pkg install scikit-learn
